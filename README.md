# 🎮 Tic Tac Toe Buddies

A real-time, interactive Tic Tac Toe web application built with modern web technologies and powered by Supabase.

---

## 🚀 Live Deployment Guide (Netlify)

Follow these steps to deploy this repository live using Netlify:

1. Log in to your **Netlify Dashboard**.
2. Click **Add new site** → **Import an existing project**.
3. Select **GitHub** as your Git provider and authorize access.
4. Select the `tictactoe-buddies` repository.
5. Configure your build settings (if applicable) and click **Deploy Site**.

---

## 🛠️ Local Development Setup

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Manisasank/tictactoe-buddies.git

# 2. Navigate into the project folder
cd tictactoe-buddies

# 3. Open index.html in your browser or run via a Live Server extension
```

## 🗄️ Backend

This project uses [Supabase](https://supabase.com) for real-time game state. Run `schema.sql` against your Supabase project to set up the required tables before connecting the app.
